n C, relational operators are used to compare two values. The result of a relational operation is either 1 (true) or 0 (false). Here are the main relational operators in C:

== (Equal to):

Checks if two values are equal.
Example: if (a == b)
!= (Not equal to):

Checks if two values are not equal.
Example: if (a != b)
> (Greater than):

Checks if the left value is greater than the right value.
Example: if (a > b)
< (Less than):

Checks if the left value is less than the right value.
Example: if (a < b)
>= (Greater than or equal to):

Checks if the left value is greater than or equal to the right value.
Example: if (a >= b)
<= (Less than or equal to):

Checks if the left value is less than or equal to the right value.
Example: if (a <= b)
These operators are commonly used in if statements, loops, and expressions where conditional checks are required.

The if and else statements are used in programming to make decisions based on conditions. They allow you to execute different blocks of code depending on whether a condition is true or false. Here’s how they work:

if Statement
The if statement checks a condition and executes a block of code if the condition is true.

Syntax:

c
Copy code
if (condition) {
    // Code to execute if the condition is true
}
Example:

c
Copy code
int age = 18;
if (age >= 18) {
    printf("You are eligible to vote.");
}
In this example, if age is 18 or more, the message "You are eligible to vote." is printed.
else Statement
The else statement follows an if statement and executes a block of code if the if condition is false.

Syntax:

c
Copy code
if (condition) {
    // Code to execute if the condition is true
} else {
    // Code to execute if the condition is false
}
Example:

c
Copy code
int age = 16;
if (age >= 18) {
    printf("You are eligible to vote.");
} else {
    printf("You are not eligible to vote.");
}
Here, since age is less than 18, the else block will be executed, printing "You are not eligible to vote."
if, else if, and else Statement
You can use else if to test multiple conditions.

Syntax:

c
Copy code
if (condition1) {
    // Code to execute if condition1 is true
} else if (condition2) {
    // Code to execute if condition2 is true
} else {
    // Code to execute if both conditions are false
}
Example:

c
Copy code
int number = 0;
if (number > 0) {
    printf("The number is positive.");
} else if (number < 0) {
    printf("The number is negative.");
} else {
    printf("The number is zero.");
}
This example checks if number is positive, negative, or zero, and executes the corresponding block of code.
The if, else if, and else statements help in controlling the flow of a program based on conditions.
