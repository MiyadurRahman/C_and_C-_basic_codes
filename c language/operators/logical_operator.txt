Logical operators are used to combine multiple conditions or expressions and return a boolean value (True or False). Here are the most common logical operators:

1. AND (&& or and)
Returns True if both conditions are true.
In Python, and is used, whereas in other languages like C, C++, Java, && is used.
Example:
python
Copy code
condition1 = True
condition2 = False
result = condition1 and condition2  # result will be False
2. OR (|| or or)
Returns True if at least one of the conditions is true.
In Python, or is used, while in languages like C, C++, Java, || is used.
Example:
python
Copy code
condition1 = True
condition2 = False
result = condition1 or condition2  # result will be True
3. NOT (! or not)
Reverses the boolean value of a condition.
In Python, not is used, whereas in other languages like C, C++, Java, ! is used.
Example:
python
Copy code
condition = True
result = not condition  # result will be False
These operators are widely used in decision-making statements like if, while, for, etc., to control the flow of the program based on conditions.
